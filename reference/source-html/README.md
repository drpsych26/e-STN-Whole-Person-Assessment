# Source HTML import notes

The HTML files in this directory were imported from the project file-text extraction service. GitHub contents match the extracted text exactly. They are not all byte-identical to the original uploaded files: four extracted files are shorter than the originals, likely because embedded content was omitted during extraction. The paper-pilot file's UTF-8 byte length matches the uploaded original, but a raw SHA-256 re-verification is still required.

Use these files for preliminary source review and inline-script syntax checks only. Do not treat them as canonical archival originals or as proof of complete source import. The authoritative originals remain the uploaded project files; preserve and import their raw bytes before claiming byte-for-byte reconciliation.

See `reference/SOURCE-RECONCILIATION-INVENTORY-2026-11-01.md` for hashes, byte counts, version differences and outstanding import work.
