## Required controls

1. Maintain a contributor and IP assignment register.
2. Keep copies of signed assignments and permissions in restricted company records; do not commit personal data or confidential contracts to this repository.
3. Generate an SBOM and dependency licence report for every release candidate.
4. Preserve third-party copyright and licence notices in distributed builds.
5. Block release if an assessment instrument's digital-use, display, scoring, storage or export permissions are unclear.
6. Have NZ legal counsel review the final ownership and licensing position.

## Evidence fields for each item

- Asset name and version
- Owner / licensor and source URL
- Contributor and creation date
- Copyright notice
- Licence / permission type and scope
- Permitted display, modification, storage, export and commercial use
- Territory, term, attribution and fee conditions
- Evidence file reference and reviewer
- Review date and next review date
